무엇을 확인하나요?

  1. 실시간 송수신: 두 창 모두 「연결」 후 메시지를 보내면 상대 창에 바로 나타납니다(ack 로 seq 확인).
  2. join / leave: 연결하면 자동 참여(JOIN), 「퇴장」을 누르면 LEAVE 기록 후 연결이 닫힙니다.
  3. presence: 「연결 끊기」 → 상단 상태가 INTERRUPTED, 참여자는 DISCONNECTED. 「이어서 연결(resume)」 → 끊긴 동안의 메시지를 순서대로 받고 ACTIVE 로 복귀.
  4. 수집 API: ④ 의 POST /events 로 메시지를 넣으면 채팅 창에도 실시간으로 뜹니다.
  5. 중복 방지: 같은 키로 두 번 보내면 두 번째는 DUPLICATE + 같은 seq, 로그에도 1건만. 채팅 창의 「같은 키로 재전송」도 동일.
  6. 순서 기준: 서버가 부여한 seq 가 유일한 순서. 「원본보다 먼저 도착한 수정」은 재시도 가능한 오류로 거절됩니다.
  7. 시점 복원: ⑤ 의 슬라이더를 움직이면 그 seq 시점의 참여자/presence/메시지(수정·삭제 반영)/안 읽은 수가 복원됩니다.
